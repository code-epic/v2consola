Fusionar ramas ¡Mantengamos el código limpio y seguro!
Importante: Revisar cambios antes de fusionar ramas

Antes de fusionar cualquier rama, es fundamental visualizar y validar los cambios para garantizar la estabilidad del código. Recuerda:
- Rama destino: Es la rama donde se encuentra actualmente el código (ej: develop).
- Rama a fusionar (origen): Contiene los cambios que se integrarán (ej: feature/nueva-funcionalidad).
- Rama main: Solo debe recibir código ya probado, ya que es la rama que se publica en producción.

Pasos recomendados:
1. Usa git diff origen, destino o herramientas gráficas (GitHub/GitLab) para revisar diferencias.
2. Resuelve conflictos *antes* de fusionar.
3. Asegúrate de que la rama main siempre refleje una versión estable.
