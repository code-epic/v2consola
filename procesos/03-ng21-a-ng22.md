# Migración Angular 21 → Angular 22

**Fecha:** 2026-06-10
**Versión origen:** Angular 21.x
**Versión destino:** Angular 22.0.x
**TypeScript:** 5.9.3 → 6.0.3
**Node.js:** 20.19.0 → 22.22.3

## Cambios realizados

### 1. Node.js 22

Angular 22 requiere Node.js ≥ 22.22.3. Se instaló `fnm` (Fast Node Manager) y Node 22:

```bash
brew install fnm
fnm install 22.22.3
fnm default 22.22.3
eval "$(fnm env)"
```

### 2. TypeScript 6.0

Angular 22 requiere TypeScript ≥ 6.0.0. Se actualizó automáticamente al hacer `npm install`.

### 3. package.json

Se actualizaron las dependencias de Angular a `^22.0.0`:

```json
"@angular/core": "^22.0.0",
"@angular/common": "^22.0.0",
"@angular/compiler": "^22.0.0",
// ... todas las dependencias @angular/* a ^22.0.0
"@angular-devkit/build-angular": "^22.0.0",
```

### 4. tsconfig.json

Se añadieron/actualizaron las siguientes opciones:

```json
{
  "compilerOptions": {
    "strict": false,
    "esModuleInterop": true,
    "ignoreDeprecations": "6.0",
    "skipLibCheck": true
  },
  "angularCompilerOptions": {
    "fullTemplateTypeCheck": false,
    "strictInjectionParameters": false,
    "strictTemplates": false
  }
}
```

- `strict: false` — desactiva strict mode de TS 6.0 (evita ~831 errores de tipo)
- `esModuleInterop: true` — necesario para imports de librerías CommonJS
- `ignoreDeprecations: "6.0"` — suprime advertencia de deprecación de `baseUrl`
- `strictTemplates: false` — desactiva template type checking estricto de Angular 22

### 5. Librerías eliminadas

#### ng-block-ui
- **Problema:** Usa `ComponentFactoryResolver` eliminado en Angular 22
- **Última versión:** 4.0.1 (sin mantenimiento)
- **Reemplazo:** Eliminado. Las funcionalidades de bloqueo/loading se migrarán a CSS nativo + Angular CDK
- **Archivos modificados:** 10 módulos, 15 componentes, 22 templates, core-card
- **Archivos eliminados:** `core-block-ui/*` (3 archivos), `blockui.component.scss`

#### ngx-toastr
- **Problema:** Usa `ComponentFactoryResolver` eliminado en Angular 22
- **Última versión:** 20.0.5 (para Angular 21, no 22)
- **Estado:** No se usaba activamente (ToastrModule registrado pero sin llamadas a ToastrService)
- **Reemplazo:** Eliminado. Pendiente migrar a notificaciones nativas o @angular/cdk
- **Archivos eliminados:** `toastr.component.scss` (no referenciado en build)

### 6. Correcciones de código

#### moment.js
```typescript
// Antes (TS 5.x - funcionaba):
import * as moment from 'moment';
import 'moment/locale/es';

// Después (TS 6.0):
import moment from 'moment';
// moment.locale('es') ya estaba en el constructor
```

## Problemas conocidos (no bloqueantes)

1. **Sass deprecation warnings** (~300+): Uso de `@import` (deprecado en Dart Sass 3.0) y funciones `darken()`/`lighten()`. Migrar a `@use` y `color.adjust()`.
2. **CommonJS dependencies** (4): `xterm`, `@xterm/addon-fit`, `jspdf-autotable`, `qrcode`. No bloquean pero afectan optimización.
3. **`@fullcalendar/angular@5.11.5`**: Peer dependency desactualizada (requiere Angular 9-14). Funciona con `--legacy-peer-deps`.
4. **`@angular/flex-layout`**: Deprecado oficialmente. Migrar a CSS Grid/Flexbox nativo en el futuro.
