# Migración Angular 15 → Angular 16

**Fecha:** 2026-06-10
**Proyecto:** v2consola (Ela — Consola SRE)

---

## Resumen

Migración completa de Angular 14→15→16. Se corrigieron todos los archivos fuente para compatibilidad con Angular 16.2, RxJS 7 y TypeScript 5.1. Se eliminaron librerías incompatibles con Ivy.

## Comandos ejecutados

```bash
# Actualización manual de package.json a versiones consistentes Angular 16.2
# rm -rf node_modules package-lock.json
# npm install --force
```

### Dependencias eliminadas

- **ngx-perfect-scrollbar** — Incompatible con Ivy. Reemplazado por scroll nativo.
- **ng2-flatpickr** — Incompatible con Ivy. Eliminado de 6 módulos.

### Cambios en código fuente

#### ngx-perfect-scrollbar eliminado de:
- `theme-customizer.module.ts` — import y provider
- `vertical-menu.module.ts` — import y provider
- `vertical-menu.component.ts` — import de PerfectScrollbarDirective, ViewChild
- `navbar.module.ts` — import y provider
- `theme-customizer.component.html` — atributo `[perfectScrollbar]`
- `navbar-notification.component.html` — atributo `[perfectScrollbar]`
- `navbar-search.component.html` — atributo `[perfectScrollbar]`
- `navbar-bookmark.component.html` — atributo `[perfectScrollbar]`
- `vertical-menu.component.html` — atributo `[perfectScrollbar]` y `(scroll)`

#### RxJS v7 — Subject.next() requiere argumento
Se cambiaron ~20 archivos: `.next()` → `.next(undefined)`

#### entryComponents deprecado
- `core-card.module.ts` — eliminada propiedad `entryComponents`

#### relativeLinkResolution deprecado
- `app.module.ts` — eliminado `relativeLinkResolution: 'legacy'`

#### data-feather attribute binding
- `theme-customizer.component.html` — `[data-feather]="'x'"` → `data-feather="x"`

#### ng2-charts incompatible
- `investigation.module.ts` — eliminado `ChartsModule`, agregado `NO_ERRORS_SCHEMA`

#### Swiper CSS
- `swiper.component.scss` — `~swiper/swiper-bundle.css` → `swiper/css/bundle`

#### ngx-datatable (exports map workaround)
- `angular.json` — agregados CSS de ngx-datatable a `styles`
- `datatables.component.scss` — eliminados imports directos

#### MediaObserver API @angular/flex-layout
- `media.service.ts` — `media$` → `asObservable()` con `MediaChange[]`

#### Perfect scrollbar SCSS import
- `core.scss` — eliminado `@import 'perfect-scrollbar/css/perfect-scrollbar'`
