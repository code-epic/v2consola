### 2. Dependencias eliminadas

- **`ngx-perfect-scrollbar`** — No compatible con Ivy (ngcc eliminado en Angular 16). Reemplazado por scroll nativo CSS.
- **`ng2-flatpickr`** — No compatible con Ivy, no se usaba en templates.

### 3. Cambios en código fuente

#### a) RxJS v6 → v7
- `Subject.next()` requiere argumento explícito. Se cambiaron 15+ archivos:
  - `_unsubscribeAll.next()` → `_unsubscribeAll.next(undefined)`
  - `onItemCollapseToggled.next()` → `onItemCollapseToggled.next(undefined)`

#### b) @angular/flex-layout MediaObserver
- `mediaObserver.media$` fue reemplazado por `mediaObserver.asObservable()` que retorna `Observable<MediaChange[]>` (array, no objeto individual).
- Se actualizó `src/@core/services/media.service.ts` para usar la nueva API.

#### c) ngx-perfect-scrollbar eliminado de:
- `navbar.module.ts` — import y provider de PerfectScrollbarDirective
- `navbar-bookmark.component.ts`, `navbar-notification.component.html`, `navbar-search.component.html` — atributo `[perfectScrollbar]` en templates
- `vertical-menu.module.ts` — import de PerfectScrollbarDirective
- `vertical-menu.component.ts` — `PerfectScrollbarDirective` y método `onSidebarScroll()`
- `vertical-menu.component.html` — atributo `[perfectScrollbar]` y `(scroll)="onSidebarScroll()"`
- `theme-customizer.module.ts` — import de PerfectScrollbarDirective
- `theme-customizer.component.html` — atributo `[perfectScrollbar]`
- `core.scss` — import de `perfect-scrollbar/css/perfect-scrollbar`

#### d) ng2-flatpickr eliminado de:
- `tools.module.ts` — `Ng2FlatpickrModule`
- `networks.module.ts` — `Ng2FlatpickrModule`

### 4. Configuración

- `tsconfig.json`: se mantiene `skipLibCheck: true`
- `angular.json`: se agregaron estilos CSS de `@swimlane/ngx-datatable` en `styles` array

## Estado del build

- **Compilación:** ✓ Exitosa (Angular 16.2.x)
- **Chunk inicial:** ~19.17 MB
- **Advertencias:** 2 warnings por uso de `~` en imports SCSS (deprecado, no bloqueante)

## Notas técnicas

- Angular 16 eliminó **ngcc** (compilador View Engine). Toda librería debe ser Ivy-compatible.
- `@angular/flex-layout` está en `15.0.0-beta.42`, que es compatible con Angular 16 pero marcado como **deprecado**. Se migrará a CSS Grid/Flexbox nativo en una versión posterior.
- El reemplazo de `perfect-scrollbar` por scroll nativo puede afectar la experiencia de scroll en menús laterales. Evaluar si se necesita una solución alternativa (CSS `overflow-y: auto` con estilos personalizados).
